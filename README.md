# FoxStreak

[![CI](https://github.com/julius-d/fox-streak/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/julius-d/fox-streak/actions/workflows/ci.yml)

Learning app with gamification (XP + streak + levels). Flutter, Android-first, iOS + Windows + macOS ready. Local-only, no login (MVP).

## Installation

### Android

Install and receive automatic updates using Obtainium:

[<img src="https://github.com/user-attachments/assets/713d71c5-3dec-4ec4-a3f2-8d28d025a9c6" alt="Get it on Obtainium" height="80">](https://apps.obtainium.imranr.dev/redirect?r=obtainium://add/https://github.com/julius-d/fox-streak)

Or download and install the APK manually:

[![Download APK](https://img.shields.io/badge/Download-APK-orange)](https://github.com/julius-d/fox-streak/releases/latest)

### macOS

Download the latest DMG from the [Releases page](https://github.com/julius-d/fox-streak/releases/latest).

### Windows

Download the latest ZIP from the [Releases page](https://github.com/julius-d/fox-streak/releases/latest).
