# Streak on ice

You shall be able to have "Streak on ice"
A streak on ice can be won in the wheel of fortune with a smaller probability.

Later on users shall also be able to buy them, but we will put this in a different ticket.
when a user did not use the app and that would lose a streak. a streak on ice will automatically be applied so that the streak does not start again.

on the strict detail page: This shall be shown explicitly within an ice cube icon for that day.
