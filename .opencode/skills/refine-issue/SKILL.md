name: refine-issue
description: Refine an issue
---

Read the issue. It is just the first draft and may be incomplete or inconsistent.
We will refine the issue to make it more complete and consistent.
Ask the user for any missing information or clarification needed to refine the issue.
Suggest improvements to the issue, such as adding acceptance criteria, tasks, or other details.
Search in the web if helpful.

Also make sure the issue has the correct format at the beginning and end of the file, like this:
```
# Issue 00N: Short title

Status: open 

## Goal
Short description of the goal of the issue.

```

When the issue is refined, ask the user if it shall be updated with the refined version and if yes, update the issue accordingly. In case of an update add a `Refined-at` timestamp to the status line of the issue.
