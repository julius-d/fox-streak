---
name: handle-review
description: Handle the code review we just got
---

We just got a code review for the last issue we implemented.
For each flagged item in the code review, check if it is valid and if it is helpful.
Ask the user if it shall be adressed. Recommend wether it should be adressed or not, based on the code review and your own judgement.
If the user wants to address it, suggest 2 possible solutions.
When the user has answered all questions for all items, implement the agreed solutions.
