---
name: new-issue
description: Create a new issue file
---

Ask the user for what the issue should be about.
Ask clarifying questions.
Suggest options how something could be realized, and ask for feedback.
The issue file should not be about how something is implemented, but only about the product requirements and how the UX should be.

Then put all this in a fresh issue file:
Check in the /issues folder and the /issues/done what is the highest available issue ID.

Then run the `/refine-issue` skill on that new issue file.
